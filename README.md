## Система учёта складских ресурсов (WMS)

Позволяет трём сущностям работать в системе - Менеджер, Кладовщик, Комплектовщик. Реализована на
Python (FastAPI), ReactJS (Vite), PostgreSQL. Используется клиент-серверное взаимодействие, можно поднять
при помощи Docker
